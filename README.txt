KLYXZONE — site

ESTRUTURA
---------
index.html  -> estrutura do site
style.css   -> visual, cores, tamanhos e responsividade
script.js   -> produtos, filtros, busca e carrinho
imagens/    -> logo e imagens dos produtos

COMO ABRIR
----------
Abra o index.html no navegador ou use o Live Server no VS Code.

IMAGENS
-------
A logo já está em imagens/logo.jpg.
As imagens dos produtos serão colocadas em imagens/ e depois relacionadas aos produtos no script.js.

PUBLICAR NA INTERNET
--------------------
Este é um site estático, então pode ser hospedado gratuitamente em serviços como GitHub Pages,
Netlify ou Vercel. Um domínio próprio (ex.: klyxzone.com.br) é opcional e normalmente é pago.
